# Wordcatcher

**Сайт:** https://vmaiorov-collab.github.io/wordcatcher/

Вставляешь ссылку на статью (BBC и т.п.), нажимаешь на слово или выделяешь фразу, видишь перевод в маленьком окошке. Слово автоматически попадает в список, из которого работают карточки и квиз.

## Запуск

Нужен Node.js 18 или новее.

    npm install
    npm start

Открой http://localhost:3000

## Как пользоваться

- **Читать**: вставь ссылку и нажми «Открыть статью». Картинки статьи (главное фото, фото с подписями) переносятся в текст. Если сайт не отдаёт статью, нажми «или вставить текст вручную».
- Клик по слову или выделение фразы: появляется перевод, слово сразу сохраняется (жёлтая подсветка в тексте). Из окошка слово можно убрать.
- **Слова**: список, поиск, удаление, экспорт в CSV.
- **Квиз**: карточки или выбор ответа, в обе стороны. Слова с ошибками попадаются чаще.

Данные хранятся в браузере (localStorage), аккаунт не нужен. Перевод идёт через публичную веб-точку Google Translate (без ключа, неофициальная: Google может её изменить или ограничить); она же даёт другие значения слова. Запасной вариант — бесплатный MyMemory, ответы без букв (например, одинокая точка) отбрасываются. Если упрёшься в дневной лимит MyMemory, запусти с `MYMEMORY_EMAIL=твой@email npm start`. Слова, сохранённые старой версией, при заходе переводятся заново один раз.

## Два режима

- **GitHub Pages** (папка `docs/`): сервера нет. Страницу статьи загружает сервис [Jina Reader](https://jina.ai/reader) (`r.jina.ai`): он открывает её как браузер и отдаёт HTML, из которого Readability вырезает текст. Если так не вышло, берётся его текстовая версия. Перевод идёт напрямую из браузера в Google, при сбое в MyMemory. Ссылки на статьи уходят Jina, а нажатые слова и фразы — сервисам перевода. У Jina без ключа есть лимит запросов в минуту; если упёрся, используй «Вставить текст вместо ссылки».
- **Локальный сервер** (`npm start`): статью скачивает твой сервер, ничего не уходит третьим сторонам, кроме нажатых слов и фраз, которые уходят в Google (или MyMemory). Фронтенд сам определяет, что сервер есть, и использует его.
