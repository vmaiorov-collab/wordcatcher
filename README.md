# Wordcatcher

**Сайт:** https://vmaiorov-collab.github.io/wordcatcher/

Вставляешь ссылку на статью (BBC и т.п.), нажимаешь на слово или выделяешь фразу, видишь перевод в маленьком окошке. Слово автоматически попадает в список, из которого работают карточки и квиз.

## Запуск

Нужен Node.js 18 или новее.

    npm install
    npm start

Открой http://localhost:3000

## Как пользоваться

- **Читать**: вставь ссылку и нажми «Открыть статью». Картинки статьи (главное фото, фото с подписями) переносятся в текст. Если сайт не отдаёт статью, нажми «или вставить текст вручную».
- Клик по слову или выделение фразы: появляется перевод **по смыслу в этом предложении** (переводится всё предложение, и из него выбирается значение слова; под цитатой показан перевод предложения целиком — так понятны и идиомы), слово сразу сохраняется (жёлтая подсветка в тексте). Из окошка слово можно убрать. Кнопка «▶» под словом показывает транскрипцию и включает произношение (запись носителя из бесплатного Dictionary API, а если записи нет — английский голос браузера); «Послушать предложение» читает предложение целиком. Такие же кнопки есть в словаре и в квизе.
- **Слова**: список, поиск, удаление, экспорт в CSV. Кнопка «На проверку» у слова отмечает его для квиза; фильтр «Все / На проверку» и «Отметить все показанные».
- **Квиз**: по отмеченным словам или по всем. Режимы: «Написать по-английски» (видишь перевод, пишешь слово; подсказки: первая буква, потом предложение с пропуском; опечатка в одну букву засчитывается как «почти»), карточки и выбор ответа в обе стороны. Слова с ошибками попадаются чаще.

Данные хранятся в браузере (localStorage), аккаунт не нужен. Перевод идёт через публичную веб-точку Google Translate (без ключа, неофициальная: Google может её изменить или ограничить); она же даёт другие значения слова. Если этот адрес Google не отвечает (лимит или блокировщик рекламы), используется встроенный переводчик браузера (Translator API: перевод на устройстве, в браузерах Apple — движок Apple, если браузер его поддерживает), затем второй адрес Google, и только потом бесплатный MyMemory: из его вариантов отбрасываются мусорные (одинокая точка, заголовки Википедии вроде «Дафф, Хилари» для *devoted*). Слова, переведённые не через Google, при следующем заходе или клике тихо переводятся заново через Google. Если упрёшься в дневной лимит MyMemory, запусти с `MYMEMORY_EMAIL=твой@email npm start`.

## Два режима

- **GitHub Pages** (папка `docs/`): сервера нет. Страницу статьи загружает сервис [Jina Reader](https://jina.ai/reader) (`r.jina.ai`): он открывает её как браузер и отдаёт HTML, из которого Readability вырезает текст. Если так не вышло, берётся его текстовая версия. Перевод идёт напрямую из браузера в Google, при сбое в MyMemory. Ссылки на статьи уходят Jina, а нажатые слова и фразы — сервисам перевода. У Jina без ключа есть лимит запросов в минуту; если упёрся, используй «Вставить текст вместо ссылки».
- **Локальный сервер** (`npm start`): статью скачивает твой сервер, ничего не уходит третьим сторонам, кроме нажатых слов и фраз, которые уходят в Google (или MyMemory). Фронтенд сам определяет, что сервер есть, и использует его.

## Приложение для Android

Папка `android/`: то же веб-приложение из `docs/` в нативной оболочке (WebView), без отдельной копии кода. Что добавляет оболочка:

- **Статьи без Jina.** Страницу скачивает сам телефон (как браузер), текст вырезает Readability прямо в приложении. Ссылки не уходят третьим сторонам; Jina остаётся запасным вариантом.
- **«Поделиться» → Wordcatcher.** В браузере на странице статьи нажми «Поделиться» и выбери Wordcatcher: статья откроется в приложении. Выделенный текст тоже можно отправить так.
- **Озвучка** через системный синтез речи Android, **экспорт CSV** через системный выбор папки.
- Слова хранятся в приложении (отдельно от сайта в браузере).

**Установка.** Готовый APK собирает GitHub Actions (`.github/workflows/android.yml`): после слияния в `main` он лежит в релизе [android-latest](https://github.com/vmaiorov-collab/wordcatcher/releases/tag/android-latest), для остальных веток — в артефактах запуска. Скачай `wordcatcher.apk` на телефон и открой; Android попросит разрешить установку из этого источника.

**Сборка вручную.** Нужны JDK 17+ и Android SDK (платформа 35):

    cd android
    ./gradlew assembleRelease

APK появится в `android/app/build/outputs/apk/release/`. Все сборки подписаны одним ключом `android/wordcatcher.keystore` (лежит в репозитории, пароль `android`), поэтому новая версия ставится поверх старой. Ключ публичный: ставь APK только из этого репозитория или собранный самостоятельно.
