# Wordcatcher

**Сайт:** https://vmaiorov-collab.github.io/wordcatcher/

Вставляешь ссылку на статью (BBC и т.п.), нажимаешь на слово или выделяешь фразу, видишь перевод в маленьком окошке. Слово автоматически попадает в список, из которого работают карточки и квиз.

## Запуск

Нужен Node.js 18 или новее.

    npm install
    npm start

Открой http://localhost:3000

## Как пользоваться

- **Читать**: вставь ссылку и нажми «Загрузить». Если сайт не отдаёт статью, нажми «или вставить текст вручную».
- Клик по слову или выделение фразы: появляется перевод, слово сразу сохраняется (жёлтая подсветка в тексте). Из окошка слово можно убрать.
- **Слова**: список, поиск, удаление, экспорт в CSV.
- **Квиз**: карточки или выбор ответа, в обе стороны. Слова с ошибками попадаются чаще.

Данные хранятся в браузере (localStorage), аккаунт не нужен. Перевод идёт через бесплатный MyMemory API; если упрёшься в дневной лимит, запусти с `MYMEMORY_EMAIL=твой@email npm start`.

## Два режима

- **GitHub Pages** (папка `docs/`): сервера нет. Страницу статьи загружает сервис [Jina Reader](https://jina.ai/reader) (`r.jina.ai`): он открывает её как браузер и отдаёт HTML, из которого Readability вырезает текст. Если так не вышло, берётся его текстовая версия. Перевод идёт напрямую через MyMemory. Ссылки на статьи при этом уходят этим двум сервисам. У Jina без ключа есть лимит запросов в минуту; если упёрся, используй «Вставить текст вместо ссылки».
- **Локальный сервер** (`npm start`): статью скачивает твой сервер, ничего не уходит третьим сторонам, кроме текста слов в MyMemory. Фронтенд сам определяет, что сервер есть, и использует его.
